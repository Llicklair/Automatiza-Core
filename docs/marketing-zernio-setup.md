# Conecta tus redes sociales (Zernio)

AutomatizaCore publica en tus redes sociales (Instagram, Facebook, LinkedIn,
X/Twitter, TikTok…) a través de **Zernio**, un servicio especializado y socio
oficial de las plataformas. Creas tu cuenta de Zernio (gratis) y la conectas a
AutomatizaCore **una sola vez**.

> **¿Por qué Zernio?** Conectar redes sociales "a mano" exige permisos de
> desarrollador y revisiones que tardan meses. Zernio ya los tiene: tú solo te das
> de alta y conectas tus cuentas en minutos.

## Resumen (≈5 minutos)

1. Crea una cuenta gratis en Zernio.
2. Copia tu API key.
3. Pégala en AutomatizaCore (**Marketing → Cuentas**).
4. Conecta tus redes.
5. Publica.

---

## Paso 1 · Crea tu cuenta de Zernio (gratis)

- Entra en <https://zernio.com> y regístrate (puedes usar **Continuar con Google**).
  No pide tarjeta.
- El plan gratuito incluye **2 redes sociales por cuenta** (por email).

## Paso 2 · Consigue tu API key

- En Zernio, ve a **Dashboard → API Keys** (o **Settings → API Keys**).
- Pulsa **Create API Key** y **cópiala en el momento** (solo se muestra una vez).
  Empieza por `sk_`.

> _[captura: pantalla de API Keys en Zernio]_

## Paso 3 · Añádela en AutomatizaCore

- Abre **Marketing → Cuentas**.
- En **Cuentas de Zernio**, escribe una etiqueta (p. ej. tu email) y pega la API key.
- Pulsa **Añadir y validar**. Si la key es correcta, tu cuenta aparecerá en la lista.

> _[captura: sección "Cuentas de Zernio"]_
>
> La API key se guarda **cifrada** en AutomatizaCore.

## Paso 4 · Conecta tus redes

- En **Conectar redes**, pulsa **Conectar** en la red que quieras (Instagram,
  Facebook…).
- Se abrirá la ventana de la red para que autorices el acceso. Acepta.
- Al volver, la red aparecerá como **Conectado**. ¡Listo!

## Truco · Conecta más de 2 redes gratis

El plan gratuito da 2 redes **por email**. ¿Necesitas más sin pagar?

1. Crea **otra cuenta de Zernio con otro email** y consigue su API key (Paso 2).
2. Añádela también en AutomatizaCore con **"Añadir otra"**.
3. Al conectar una red, elige con qué cuenta de Zernio hacerlo (selector de arriba).

Cada email te da 2 redes gratis.

## Paso 5 · Publica

Ya puedes crear posts (pestaña **Crear**), programarlos (**Programados**), ver
analítica (**Analítica**) o pedir un plan a la IA (**Plan IA**). Todo se publica por
la cuenta de Zernio que conectaste.

---

## Problemas frecuentes

- **"La API key no es válida"** — revisa que la copiaste entera y que empieza por
  `sk_`. Si dudas, genera otra en Zernio → API Keys.
- **La red no aparece tras conectar** — vuelve a pulsar **Conectar**; algunas redes
  piden elegir página/cuenta. Espera unos segundos (se detecta automáticamente).
- **"Tu cuenta de Zernio no tiene ningún profile"** — entra en zernio.com y crea un
  *Profile* (espacio de trabajo) antes de conectar.
- **Tus datos** — la API key se guarda cifrada en AutomatizaCore. Los tokens de tus
  redes viven en **tu propia cuenta de Zernio**, no en AutomatizaCore.

## Seguridad

Trata tu API key como una contraseña. Si se expone, **rótala** en Zernio → API Keys
(la antigua deja de funcionar y pegas la nueva en AutomatizaCore).
