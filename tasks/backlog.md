# Backlog operativo — AutomatizaPyme MVP

> **Fuente**: roadmap ejecutivo en [`tasks/roadmap.md`](./roadmap.md). Decisiones consensuadas en `DISCUSION_OTRA_IA.md`.

## Convenciones

- **ID**: prefijo categoría + número. Categorías:
  - `DEC` decisión humana (fundador / abogado / gestor)
  - `ALB` Alembic + datos
  - `SEC` seguridad
  - `FAC` Verifactu + facturación
  - `MOD` modelos AEAT generación
  - `PRES` presentación telemática AEAT
  - `UI` UI/UX frontend
  - `OPS` customer operations
  - `AI` AI Act compliance
  - `INT` integraciones bancarias / N43
  - `QA` testing + CI
  - `DIS` distribución Electron
  - `CONT` contingencia
  - `BAK` backup
  - `MIG` migración desde competidores
  - `MULTI` multi-actor
  - `I18N` internacionalización cooficiales
- **Owner**: `dev1` backend senior · `dev2` fullstack · `dev3` frontend/UX · `fund` fundador · `abog` abogado · `gest` gestor · `agen` agencia traducción
- **Coste**: días-persona dev (decimales válidos) o `adm` para acciones administrativas
- **Sprint**: 0 = decisiones admin pre-dev, 1-9 = sprints dev, ∞ = post-MVP
- **Depende**: IDs separados por coma
- **Estado**: TODO · WIP · BLOCKED · DONE
