## 🟡 RENDIMIENTO — Requests lentas en toda la app

### PERF-01: `BaseHTTPMiddleware` bufferiza toda la respuesta antes de enviarla

**Archivos afectados**:
- `backend/app/main.py` — `SecurityHeadersMiddleware`
- `backend/app/middleware/request_logger.py` — `RequestLoggerMiddleware`

**Problema**: `BaseHTTPMiddleware` de Starlette es un [known performance issue](https://www.starlette.io/middleware/#basehttpmiddleware). Lee el cuerpo completo de la respuesta en memoria antes de pasarla al cliente. Esto:
- Añade latencia en **cada** request
- Bloquea el streaming de respuestas grandes (PDFs, Excel, informes)
- Incrementa uso de RAM con respuestas grandes

**Fix**: Convertir ambos a middleware puro ASGI (`@app.middleware("http")` decorator pattern o clase ASGI pura).

---

### PERF-02: Pipeline LLM inherentemente lento + sin feedback visual

**Archivos**: `backend/app/agents/orchestrator/_core.py`

**Problema**:
- Cada acción IA ejecuta: `init_tenant → load_knowledge → plan (LLM) → dispatch (LLM) → summarize (LLM)`
- Mínimo 3 llamadas LLM por tarea simple → 5-15s en condiciones normales
- El timeout por agente es 120s con 1 retry → worst case **240s por agente**
- El frontend hace polling cada N segundos pero el usuario no ve progreso real

**Fix parcial**: Reducir timeout de 120s a 60s para fallos más rápidos. El streaming ya existe via WebSocket pero puede necesitar mejoras en el frontend.

## 🔵 CONSISTENCIA — No crítico pero genera confusión

### CON-01: `hr_documents.ts` y `generative_ui.ts` no están en el barrel export `index.ts`

**Archivo**: `frontend/src/lib/api/index.ts`

Las páginas que los usan importan directamente del módulo:
```ts
// rrhh/documentos/page.tsx
import { hrDocuments } from "@/lib/api/hr_documents"; // ✅ funciona
import type { HRDocument } from "@/lib/api/hr_documents";

// sandbox/page.tsx  
import { generativeUI } from "@/lib/api/generative_ui"; // ✅ funciona
```

Funcionan correctamente pero rompen el patrón `api.X.Y()` del resto de la app.

**Fix**: Añadir ambos a `index.ts` para consistencia:
```ts
import { hrDocuments } from "./hr_documents";
import { generativeUI } from "./generative_ui";

export const api = {
  ...
  hrDocuments,
  generativeUI,
};
```

## ❌ Falsos positivos — Claims incorrectos descartados tras verificación manual

**Agente frontend:**
1. "63 páginas sin `'use client'`" → FALSO. Todas las páginas verificadas tienen `"use client"` como primera línea.
2. "`system.ts` llama `/health` incorrecto" → FALSO. `/health` está en el root de FastAPI, no bajo `/api/v1`. El frontend es correcto.

**Agente backend:**
3. "Ruta `/reports` no registrada" → FALSO. `api_router.include_router(reports.router)` en router.py + `reports/__init__.py` ensambla correctamente los sub-routers.
4. "Workflow agent solo 1 tool" → FALSO. Usa arquitectura determinista (`_compile_deterministic_steps`), no @tool. Es un diseño diferente, no es un bug.
5. "RAG agent incompleto" → FALSO. Tiene 2 `@tool` completamente implementados: `search_documents` y `answer_from_documents`.
